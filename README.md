# Fundamentals of Computing: Tic Tac Toe Final Project

This is our CMPS1134 Fundamentals of Computing final project: a multi-page website built with HTML, CSS, and JavaScript, featuring an interactive two-player Tic Tac Toe game.

## Pages
- **Home:** course description and team mission
- **Our Team:** profiles of each team member
- **Video Gallery:** each member's video assignment
- **Game:** the playable Tic Tac Toe game, with instructions and an explanation of how the code works
- **Documentation:** our written report, presentation slides, testing log, and a code snippet

## About the Game
Two players, O and X, take turns placing marks on a 3x3 board. The first player to get three marks in a row wins, and the winning squares are highlighted. If the board fills up with no winner, the game is a draw. A restart button resets the board.
