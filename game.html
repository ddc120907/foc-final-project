♡ Tic Tac Toe ♡

Player O's turn

How to Play

  1. Two players take turns. Player O goes first, then Player X.
  2. Click an empty square to place your mark.
  3. The first player to get three marks in a row (across, down, or diagonally) wins, and the winning squares turn green.
  4. If all nine squares are filled and nobody has won, the game is a draw.
  5. Click Restart Game to start over.

How the Code Works

The game is built with HTML, CSS, and JavaScript. HTML creates the nine squares, CSS arranges them into a 3x3 grid, and JavaScript runs the game logic. The board is stored in an array of nine items that start empty and fill with "O" or "X" as players take turns. When a square is clicked, the code first checks that the game isn't over and the square is empty, then places the current player's mark. After every move, it compares the board against a list of eight winning combinations (three rows, three columns, and two diagonals). If all three squares in a combination match, that player wins and those squares turn green. If the board fills up with no winner, the game declares a draw. The restart button clears the array and the squares and gives the first turn back to Player O.
